# advisor-psychologist — совет линз по психологической помощи

Одиннадцать психологических подходов разбирают одну твою ситуацию вслепую, скептики проверяют выводы, safety-ревьюер читает готовый вердикт последним и может его стереть.

> [!WARNING]
> **Это не терапия и не кризисная служба.** Формат — структурированная самопомощь и психообразование рядом с живым терапевтом. При признаках риска совет останавливается и отправляет к людям: **112** (или местный экстренный номер) и **findahelpline.com**. Безопасность формата «AI-совет по психологической помощи» в исследованиях не установлена — предохранители здесь стоят вместо отсутствующих данных, а не как гарантия. Подробности — в [NOTICE.md](NOTICE.md).

## Зачем

Разобраться хочется сейчас, а разбираться не с кем: живой специалист будет через недели, интернет выдаёт десять противоречивых советов, чат-бот соглашается с той версией событий, которую ты принёс.

Здесь соглашаться не с кем. Одиннадцать методологий-линз получают одну обезличенную выжимку и работают одновременно, не видя ответов друг друга. Отдельный проверяющий ищет места, где инструмент пересказал тебе твою же версию, и пишет об этом прямо в ответе.

Потолок ответа — три действия, сколько бы полезного ни нашли одиннадцать линз.

## Как поставить

Открой Claude Code и вставь этот блок в строку ввода:

```
Ты — установщик. Выполни ровно эти шаги и ничего сверх них:
1. Bash: claude plugin marketplace add https://github.com/beCyborg/jadlis-plugins.git
2. Bash: claude plugin install advisor-psychologist@jadlis --config MEMORY_DIR=~/advisors-memory/Психотерапевт
3. Скажи мне одной строкой: «Отправь /advisor-psychologist привет и заполни кризисные контакты».
```

Те же две команды руками, если Bash в приложении недоступен:

```bash
claude plugin marketplace add https://github.com/beCyborg/jadlis-plugins.git
claude plugin install advisor-psychologist@jadlis --config MEMORY_DIR=~/advisors-memory/Психотерапевт
```

Флаг `--config` не пропускай: значение по умолчанию из манифеста автоматически не подставляется. Без него совет остановится на первом запуске и попросит указать папку (настроить можно и потом — `/plugin` → advisor-psychologist → настройки).

**Третий шаг — кризисные контакты.** Запусти `/advisor-psychologist привет`: совет развернёт папку памяти, создаст `~/advisors-memory/Психотерапевт/_local/crisis-contacts.md` с шаблоном и остановится. Впиши номера своей страны (сверь по официальным сайтам служб), удали строку `<!-- НЕ ЗАПОЛНЕНО -->` — и совет заработает. Гейт намеренно жёсткий: разбор без работающих контактов — ровно тот режим отказа, от которого защищает safety-протокол.

Ставится плагин и из отдельного маркетплейса репозитория — `becyborg-psy`:

```bash
claude plugin marketplace add https://github.com/beCyborg/jadlis-advisor-psychologist.git
claude plugin install advisor-psychologist@becyborg-psy --config MEMORY_DIR=~/advisors-memory/Психотерапевт
```

Полный HTTPS-URL — защита от клона по SSH: shorthand `owner/repo` уходит на SSH, а SSH-ключа на GitHub у нового пользователя обычно нет.

## Как пользоваться

Одна строка, обычным языком:

```
/advisor-psychologist разбери повторяющийся эпизод: пауза в переписке — и включается тревога
/advisor-psychologist выбираю между двумя работами, и обе тянут в разное
/advisor-psychologist пересобери карты за квартал
```

Режим совет выбирает сам по трём осям — острота, масштаб, новизна (тег `advisor-psychologist--v1.2.0`):

| Режим | Когда включается | Что получишь |
|---|---|---|
| **SAFE-STOP** | сработал скрин риска | заземление, твои кризисные контакты, маршрут к живому — без разбора |
| **LIGHT** | эпизод, знакомый паттерн или остро сейчас | 2–3 линзы, 10–15 строк, **ровно один** шаг |
| **COUNCIL** | паттерн, развилка, крупная новая тема | все 11 линз, скептики, вердикт файлом |
| **REVIEW** | раз в квартал или по назначенному revisit | пересборка карт, скоринг прошлых предсказаний |

LIGHT — ожидаемое большинство обращений; при сомнении совет берёт его. Два правила срабатывают без спроса: после 23:00 — только LIGHT (ночные выводы редко доживают до утра), а на пятом обращении за неделю совет назовёт это вслух и спросит про шаг в сторону живого контакта.

Всё, что совет пишет, лежит обычными markdown-файлами в `MEMORY_DIR`: `Совет.md` (хаб), `Журнал сессий.md`, `Домашка.md`, `Контекст/`, `Вердикты/`, `_local/`. Папку можно положить внутрь Obsidian-vault — тогда работают wikilinks и callouts.

## Границы и стоимость

Чего совет не делает никогда: не диагностирует и не использует DSM-ярлыки, не считает баллы опросников, не трогает медикаменты, не ведёт кризис (только маршрутизирует), не даёт больше трёх действий и не называет себя терапией. Протоколы, открывающие травматический материал, помечены тиром REQUIRES-THERAPIST и уходят в секцию «вынести на живую сессию».

- **Подписка.** Нужен Claude Code с поддержкой плагинов и Workflow и подписка, на которой доступен Opus. Внешних сервисов, API-ключей и MCP-серверов плагин не требует — оплаты сверх подписки нет.
- **Расход лимитов.** COUNCIL — порядка 44 вызовов модели (11 линз + куратор + по три скептика на утверждение + синтезатор + safety-ревьюер), минуты ожидания и заметный кусок недельного лимита; он для развилок, а не «поговорить».
- **Приватность.** Сырой текст в субагентов не уходит: перед созывом собирается анонимизированное досье (имена → роли, даты и города убраны, чужие медицинские и юридические факты вырезаны). Содержимое папки памяти приватное — проверь, куда синхронизируется родительская папка, и не клади её в публичный git.
- **Частые отказы.** «Не задана папка памяти» → задать `MEMORY_DIR`. «Впиши локальные номера…» → заполнить `_local/crisis-contacts.md`. Вердикт с пометкой `UNREVIEWED` → safety-ревьюер не отработал: читать с осторожностью, прогон повторить.

## Обновление

У сторонних маркетплейсов авто-обновление у получателя выключено по умолчанию — новая версия приезжает по команде:

```bash
claude plugin update advisor-psychologist@jadlis
```

Либо один раз включить авто-обновление: `/plugin` → **Marketplaces** → `jadlis`. Ставил из `becyborg-psy` — подставляй его вместо `jadlis`. История версий — [CHANGELOG.md](plugins/advisor-psychologist/CHANGELOG.md).
