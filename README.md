# adv-psy — совет линз по психологической помощи для Claude Code

Плагин для Claude Code: одиннадцать методологий-линз разбирают твою ситуацию, каждая со своей рамки, скептики проверяют выводы, safety-ревьюер читает готовый вердикт последним и может его заблокировать.

> [!warning]
> **Это не терапия и не кризисная служба.** Формат — структурированная самопомощь и психообразование рядом с живым терапевтом. При признаках риска совет останавливается и отправляет к людям: **112** (или местный экстренный номер) и **findahelpline.com**.
>
> Безопасность формата «AI-совет по психологической помощи» в исследованиях не установлена. Все предохранители здесь стоят именно поэтому — они замена отсутствующим данным, а не гарантия. Подробности — в [NOTICE.md](NOTICE.md).

## Установка — три шага

```bash
# 1. Подключить marketplace
CLAUDE_CODE_PLUGIN_PREFER_HTTPS=1 claude plugin marketplace add beCyborg/adv-psy-plugin

# 2. Поставить плагин, указав папку для памяти совета
claude plugin install adv-psy@becyborg-psy --config PSY_MEMORY_DIR=~/adv-psy
```

Флаг `--config` не пропускай: значение по умолчанию из манифеста автоматически не подставляется. Без него совет остановится на первом же запуске и попросит указать папку (настроить можно и потом — `/plugin` → adv-psy → настройки).

**3. Заполнить кризисные контакты.** Запусти `/adv-psy:adv-psy привет` — совет развернёт папку памяти и создаст `~/adv-psy/_local/crisis-contacts.md` с шаблоном, после чего остановится. Впиши в файл номера своей страны (проверь по официальным сайтам служб), удали строку `<!-- НЕ ЗАПОЛНЕНО -->` — и совет заработает.

Гейт намеренно жёсткий: разбор без работающих контактов — ровно тот режим отказа, от которого защищает safety-протокол.

## Как пользоваться

```
/adv-psy:adv-psy разбери повторяющийся эпизод: пауза в переписке — и включается тревога
```

Совет сам решает, какой режим нужен:

| Режим | Когда включается | Что получишь |
|---|---|---|
| **SAFE-STOP** | сработал скрин риска | заземление, твои кризисные контакты, маршрут к живому — без разбора |
| **LIGHT** | эпизод, знакомый паттерн или остро прямо сейчас | 2–3 линзы, 10–15 строк, **ровно один** шаг |
| **COUNCIL** | паттерн, развилка, крупная новая тема | все 11 линз, скептики, полный вердикт файлом |
| **REVIEW** | раз в квартал или по назначенному revisit | пересборка карт, скоринг прошлых предсказаний |

LIGHT — ожидаемое большинство обращений; при сомнении совет берёт его. COUNCIL — это ~44 вызова модели, минуты ожидания и заметный расход лимитов; он нужен для развилок, а не для «поговорить».

Ещё два правила, которые сработают без спроса: после 23:00 — только LIGHT (ночью выводы держатся хуже), а при пятом обращении за неделю совет назовёт это вслух и спросит про шаг в сторону живого контакта.

## Что совет не делает никогда

Не диагностирует и не использует DSM-ярлыки. Не считает баллы опросников. Не трогает медикаменты. Не ведёт кризис — маршрутизирует. Не запускает протоколы, которые открывают травматический материал (они помечены тиром REQUIRES-THERAPIST и уходят в секцию «вынести на живую сессию»). Не даёт больше трёх действий. Не переформулирует горе позитивно. Не называет себя терапией.

## Одиннадцать линз

КПТ по Беку · схема-терапия · ACT · CFT и самосострадание · навыки DBT · привязанность и IPT · горе (dual-process) · поведенческая активация и экспозиция · перфекционизм и непереносимость неопределённости · общие факторы и мотивационное интервью · калибровка доказательности 2026.

Одиннадцатая — не метод, а калибратор: она держит поправки, найденные при верификации, чтобы остальные линзы не тиражировали числа, которые проверку не прошли.

Линзы не регистрируются как отдельные скиллы и не висят в контексте: их читает workflow совета.

## Память

Всё, что совет пишет, лежит в папке `PSY_MEMORY_DIR` — обычные markdown-файлы:

```
~/adv-psy/
├── Совет.md                  хаб: режимы, границы, что где лежит
├── Журнал сессий.md          по строке на обращение, append-only
├── Домашка.md                активные пункты со статусами
├── Контекст/                 карта схем и режимов, ключевые формулировки
├── Вердикты/                 COUNCIL-вердикты, имена нейтральные датированные
└── _local/                   профиль со счётчиком и кризисные контакты
```

Папку можно положить внутрь Obsidian-vault — тогда работают wikilinks и callouts; без Obsidian всё то же самое, просто файлами. Содержимое приватное: проверь, куда синхронизируется родительская папка, и не клади её в публичный git.

Сырой контекст в субагентов не уходит: перед созывом совета главная сессия собирает анонимизированное досье (имена → роли, локации и даты убраны, юридические и медицинские факты третьих лиц вырезаны).

## Три частых отказа

| Что видишь | Почему | Что делать |
|---|---|---|
| «Не задана папка памяти совета» | `PSY_MEMORY_DIR` пуст | `/plugin` → adv-psy → настройки, указать путь; или переустановить с `--config` |
| «Впиши локальные номера… пока маркер на месте, совет не созывается» | шаблон контактов не заполнен | вписать номера в `_local/crisis-contacts.md`, удалить строку с `НЕ ЗАПОЛНЕНО` |
| Вердикт с пометкой `UNREVIEWED` | safety-ревьюер не отработал | читать с осторожностью, при сомнениях выносить на живую сессию; повторить прогон |

## Что внутри

```
plugins/adv-psy/
├── skills/adv-psy/     скилл: триаж, анонимизация, вызов совета, запись в память
│   ├── protocols/      триаж-гейт, safety, вердикт, память, спецификация линзы
│   └── references/     конфликты методов и маршрутизация «мишень → линза»
├── lenses/             11 линз + общий калибровочный дайджест (не скиллы — данные)
├── workflows/          council-psy.js — fan-out → скептики → синтез → safety-ревью
├── agents/             воркер совета (Opus, effort xhigh)
├── shared/             контракт записи в память
└── assets/             шаблоны контактов и профиля, скелет папки памяти
```

Требования: Claude Code с поддержкой плагинов и Workflow; подписка, на которой доступен Opus. Внешних сервисов, API-ключей и MCP-серверов плагин не требует.
