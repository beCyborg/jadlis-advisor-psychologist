# Журнал сессий

Append-only. Одна запись на обращение, новые сверху не вставлять — дописывать вниз. Задним числом записи не редактируются: ошибочный вердикт остаётся с пометкой, иначе на промахах нельзя учиться.

Поле «исход» заполняется **позже**, при revisit. Пустое поле лучше выдуманного.

Формат записи:

```markdown
## ГГГГ-ММ-ДД — РЕЖИМ

- **запрос:** одной строкой, своими словами
- **что опознали:** режим / схема / паттерн
- **рефрейм:** одна формулировка
- **домашка:** что назначено (или «нет»)
- **скорость самокоррекции:** сколько прошло от запуска паттерна до момента, когда удалось его назвать
- **revisit:** дата или «нет»
- **исход:**
```
