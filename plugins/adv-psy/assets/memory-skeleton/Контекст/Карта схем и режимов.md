# Карта схем и режимов

Живой файл. Обновляется **только дописыванием** — датированными блоками «Update ГГГГ-ММ:», не перезаписью. Формулировка, которая перестала быть точной, — не ошибка, которую надо стереть, а информация о движении: без неё нельзя ответить на главный вопрос ревью «что изменилось за квартал».

Всё здесь — **гипотезы о паттернах**, а не диагнозы. Никаких DSM-ярлыков.
