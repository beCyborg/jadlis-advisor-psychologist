# Домашка

Статусы: `активна` → `сделана` / `не пошла` / `переделана` / `снята`.

**«Не пошла» — сигнал к редизайну задания, а не к упрёку.** Если задание не сделано — задание было неправильным. Невыполненная домашка без переделки подкрепляет вывод «я даже этого не могу», то есть работает прямо против цели.

При третьем подряд «не пошла» по одной теме тема уходит в REVIEW, а не получает четвёртое задание.
